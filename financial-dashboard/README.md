# Financial Dashboard

## Description

The Financial Dashboard is an interactive web application built using Streamlit that allows users to track stock performance, visualize financial data, and gain insights through AI analysis. The application fetches real-time stock data, displays key metrics, and provides a user-friendly interface for managing a watchlist of stocks.

## Features

- Fetch and display stock data from Yahoo Finance.
- Interactive charts for visualizing stock price trends.
- AI-powered insights and analysis based on financial metrics.
- User-friendly interface for managing a stock watchlist.
- Customizable themes and styles for a personalized experience.

## Installation

To set up the Financial Dashboard, follow these steps:

1. Clone the repository:

   ```
   git clone https://github.com/yourusername/financial-dashboard.git
   cd financial-dashboard
   ```

2. Create a virtual environment (optional but recommended):

   ```
   python -m venv venv
   source venv/bin/activate  # On Windows use `venv\Scripts\activate`
   ```

3. Install the required dependencies:
   ```
   pip install -r requirements.txt
   ```

## Usage

To run the Financial Dashboard, execute the following command:

```
streamlit run src/FinancialDashboard.py
```

Open your web browser and navigate to `http://localhost:8501` to access the application.
